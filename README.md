# FitLog – Workout Library

## Short Description

FitLog is a workout library web application where users can explore workouts, create a daily workout plan, save workouts, and track basic workout statistics.

## Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* DaisyUI
* REST API
* LocalStorage.

## Key Features

1. **Workout Library** – Browse different workouts and view their details.
2. **Daily Workout Plan** – Add up to 5 workouts to today's plan.
3. **Save Workouts** – Save workouts for later.
4. **Workout Statistics** – View total exercises, minutes, and calories.
5. **Responsive Design** – Works on desktop, tablet, and mobile devices.
